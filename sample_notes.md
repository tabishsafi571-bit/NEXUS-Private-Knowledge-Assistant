
# NEXUS Sample Knowledge Base

## Project Privacy
NEXUS searches text and Markdown documents stored in a folder selected by the user.
The basic search runs locally on the user's computer.

## Study Notes
Electric current is the rate of flow of electric charge.
The SI unit of electric current is the ampere.
Ohm's law states that voltage equals current multiplied by resistance, when physical conditions remain constant.

## Project Limitations
The initial version supports TXT and Markdown files.
The basic retrieval system uses keyword matching.
Optional local AI responses require a running Ollama service and an installed compatible model.
